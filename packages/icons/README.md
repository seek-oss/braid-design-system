# `@braid-design-system/icons`

SVG assets for Braid icons.

```sh
npm install @braid-design-system/icons
```

```js
import icon from '@braid-design-system/icons/add.svg';
```

Each icon has a default drawing (`add.svg`). When a platform needs a different drawing, the filename is suffixed (`.ios`, `.android`, `.web`, `.native`). Filled drawings use a `Fill` suffix (`bookmarkFill.svg`).
