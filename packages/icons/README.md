# `@braid-design-system/icons`

SVG assets for Braid icons. Import files directly; platform kits wrap them in their own components.

```sh
npm install @braid-design-system/icons
```

```js
import icon from '@braid-design-system/icons/iconName.svg';
```

Unsuffixed files are the default drawing. Use `.web`, `.ios`, `.android` or `.native` when a platform needs a different drawing (`@braid-design-system/icons/iconName.web.svg`).
