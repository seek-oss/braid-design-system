Add `@braid-design-system/icons`, the SVG assets for Braid icons.

Install and import files by name:

```sh
npm install @braid-design-system/icons
```

```js
import add from '@braid-design-system/icons/add.svg';
```

Each icon has a default drawing (`add.svg`). Filled drawings use an `-active` suffix (`bookmark-active.svg`). See the [full icon suite](https://github.com/seek-oss/braid-design-system/tree/master/packages/icons/source) for every file.
